# Where to put your own files

- photos/      -> her pictures (jpg/png). Then set the path in src/data/birthdayData.ts, e.g. "/assets/photos/us.jpg"
- music/       -> your song (mp3). Then set song.audio to "/assets/music/your-song.mp3"
- flowers/, decorations/, icons/ -> optional extra artwork

Everything else (names, captions, dates, letter, wishes) is edited in src/data/birthdayData.ts only.
